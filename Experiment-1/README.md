## 🎯 Objective

To install Oracle VirtualBox, create and configure a virtual machine, and deploy the Ubuntu Linux operating system in a virtualized environment.

## 📌 Introduction

This experiment focuses on understanding virtualization technology using Oracle VirtualBox. It involves creating a virtual machine and installing Ubuntu Linux to explore its working environment without affecting the host operating system.

## 🛠️ Software Requirements

| Software | Description |
|---|---|
| Oracle VirtualBox | Virtualization Software |
| Ubuntu Linux | Guest Operating System |
| Windows | Host Operating System |
| Ubuntu ISO File | Installation Image |

## ⚙️ Procedure

1. Download and install Oracle VirtualBox.
2. Download the Ubuntu Linux ISO image.
3. Open VirtualBox and click on **New**.
4. Enter the virtual machine name and select Ubuntu Linux.
5. Allocate RAM and processor resources.
6. Create a virtual hard disk.
7. Attach the Ubuntu ISO file to the virtual machine.
8. Start the virtual machine and follow the installation instructions.
9. Complete the installation and restart the virtual machine.
10. Verify that Ubuntu Linux is running successfully.
