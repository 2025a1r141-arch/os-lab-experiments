## 📌 Experiment Overview

This experiment focuses on the installation and configuration of **Oracle VirtualBox** and the deployment of **Ubuntu Linux** in a virtualized environment.

The practical demonstrates how virtualization technology enables users to create and operate an independent operating system without modifying the host operating system.

## 🎯 Objective

To install Oracle VirtualBox, create and configure a virtual machine, and deploy the Ubuntu Linux operating system in a virtualized environment.

## 🛠️ Technology Stack

| Technology | Purpose |
|:---|:---|
| Oracle VirtualBox | Virtualization Platform |
| Ubuntu Linux | Guest Operating System |
| Windows | Host Operating System |
| ISO Image | OS Installation Media |

## ⚙️ Practical Workflow

The experiment is performed through the following stages:

1. **Environment Setup** — Download and install Oracle VirtualBox.
2. **ISO Preparation** — Download the Ubuntu Desktop ISO image.
3. **VM Creation** — Create a new virtual machine.
4. **Resource Allocation** — Configure RAM, CPU and virtual storage.
5. **OS Deployment** — Attach the Ubuntu ISO and install Linux.
6. **Verification** — Start the virtual machine and verify the Ubuntu environment.
