## 📌 1. OBJECTIVE

To install Oracle VirtualBox, create and configure a virtual machine, and deploy the Ubuntu Linux operating system in a virtualized environment.

## 📖 2. INTRODUCTION

This experiment focuses on understanding virtualization technology and learning how to install and configure Ubuntu Linux using Oracle VirtualBox.

Oracle VirtualBox allows users to run multiple operating systems on a single physical computer without affecting the host operating system.

Ubuntu Linux is an open-source operating system widely used for programming, software development, and system administration.

## 🛠️ 3. SOFTWARE REQUIREMENTS

| S.No. | Software / Requirement |
|:---:|---|
| 1 | Oracle VirtualBox |
| 2 | Ubuntu Linux ISO Image |
| 3 | Windows Operating System |
| 4 | Minimum 4 GB RAM |
| 5 | Sufficient Free Disk Space |

## ⚙️ 4. EXPERIMENT PROCEDURE

1. Download Oracle VirtualBox from its official website.
2. Install VirtualBox on the computer.
3. Download the Ubuntu Linux ISO image.
4. Open VirtualBox and select the **New** option.
5. Enter the virtual machine name as Ubuntu Linux.
6. Select Linux as the operating system type.
7. Allocate RAM and create a virtual hard disk.
8. Attach the Ubuntu ISO image to the virtual machine.
9. Start the virtual machine.
10. Follow the installation instructions to install Ubuntu Linux.
11. Restart the virtual machine after installation.
12. Log in and verify that Ubuntu Linux is working correctly.
